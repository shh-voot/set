```
FSPL(dB) = 20*log10(d_km) + 20*log10(f_MHz) + 32.45
Rx_Power = Tx_Power + Tx_Gain + Rx_Gain - FSPL - System_Loss - Obstacle_Loss
可用条件: Rx_Power ≥ Sensitivity + Margin
```

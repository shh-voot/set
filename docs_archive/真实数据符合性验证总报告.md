### 充电模型（赛题第58行）

**公式验证**:
```python
def calculate_charging_time(soc_start, soc_target, t_full):
    if soc_target <= 0.9:
        # 快速阶段：0-90%
        time = (soc_target - soc_start) / 0.9 * 0.65 * t_full
    else:
        if soc_start < 0.9:
            # 跨两阶段
            fast_time = (0.9 - soc_start) / 0.9 * 0.65 * t_full
            slow_time = (soc_target - 0.9) / 0.1 * 0.35 * t_full
            time = fast_time + slow_time
        else:
            # 慢速阶段：90-100%
            time = (soc_target - soc_start) / 0.1 * 0.35 * t_full
    return time
```

**测试用例**（B型，t_full=30分钟）:
- 0% → 100%: 30.00分钟 ✅
- 0% → 90%: 19.50分钟（65%） ✅
- 90% → 100%: 10.50分钟（35%） ✅
- 50% → 100%: 20.25分钟 ✅

# 问题四：模拟灾害情景下的资源动态优化问题

## 题目背景

灾后通信中断可能需要将任务划分为多个阶段远程执行。元任务需要研究同步与异步两种执行方式对资源消耗的影响，包括完成时间、资源消耗及任务缺口。

## 核心约束

### 1. 任务分批执行
- 服务区数量：15个
- 批次数量：2批或3批
- 每个服务区只能在一个批次中
- 每个批次至少包含一个服务区

### 2. 批次约束
- 同一批次的服务区应满足通信覆盖要求
- 不能直接通信的服务区应该在不同批次执行
- 运输无人机和中继无人机的中继资源需求在执行期间持续消耗

### 3. 资源约束
- 电池：可充电电池与换电站
- 充电策略：两阶段充电模型（0-80%快充 + 80-100%涓流）
- 资源缺口：某一批次如果出现资源不足（电池不足、充电桩占用）

## 问题要求

### 第一问：分批方案对比
分别在服务区为2批和3批时，分析不同资源消耗方案，包括：
- 资源消耗模型（电池数量、充电桩数量）
- 比较各方案的特点

### 第二问：资源缺口分析
对某一批次出现资源不足情况，进行资源缺口计算和原因分析。

## 关键技术点

1. **批次优化** - 通信约束下的服务区分组
2. **电池管理** - 充换电调度与电池池管理
3. **资源瓶颈识别** - 任务缺口与资源不足诊断
4. **离散事件仿真** - 动态资源状态追踪

## 数据输入

- 问题一、二、三的结果
- DEM地形数据
- 通信链路参数
- 无人机性能参数
- 电池充电曲线

## 预期输出

1. **批次划分方案**
   - 2批次方案
   - 3批次方案
   - 每批次包含的服务区列表

2. **资源配置方案**
   - 电池数量需求
   - 充电桩数量需求
   - 中继机部署时间表

3. **资源消耗分析**
   - 完成时间对比
   - 能耗对比
   - 电池利用率
   - 充电桩利用率

4. **资源缺口报告**
   - 瓶颈识别
   - 缺口量化
   - 原因分析
   - 改进建议

## 技术挑战

1. **NP-hard组合优化** - 服务区分批 + 通信覆盖约束
2. **离散事件建模** - 电池充放电、任务调度、资源竞争
3. **多目标权衡** - 时间 vs 资源消耗 vs 缺口最小化

---

**解题思路**：
1. 使用图着色算法进行批次划分（通信冲突图）
2. SimPy离散事件仿真 + 电池池管理
3. 资源瓶颈诊断与敏感性分析

# 华为杯D题 - 算法思路与求解方案总结

## 📋 题目核心理解

这是一个**多层次、多约束、多目标的无人机应急物资配送优化问题**，具有以下特点：

1. **3D地形约束** - 山区地形，需考虑爬升、下降能耗和地形净空
2. **异构机队** - 3种运输无人机机型 + 中继无人机
3. **资源受限** - 8架实体无人机，有限电池和能源组件
4. **时间约束** - 医疗物资和首批保障有严格时限
5. **通信依赖** - 运输过程需持续通信，可能需要中继支持
6. **多目标权衡** - 及时性、能耗、架次数、完成时间

## 🎯 四个问题的算法策略

### 问题一：单点往返 + 货箱组批

**算法选择**: 
- **能耗计算**: 直接套用题目公式（等效航程模型）
- **组批优化**: 改进的多维背包算法

**核心思路**:
```
1. 预计算矩阵
   - 每个服务区到O01的距离、高度差
   - 每种机型在每个服务区的空载往返能耗
   - 考虑返航余量后的最大安全载荷

2. 组批算法（启发式 + 精确求解）
   - 小规模：动态规划求解背包问题
   - 大规模：贪心+首次适应递减算法
   - 约束：重量、体积、能量三重约束

3. 多目标评估
   - 架次数（主要）
   - 总能耗
   - 累计作业时间
   - 使用加权法或层次分析法
```

**预期输出**:
- 每种机型在各服务区的最大安全载荷表
- 各服务区的最优组批方案（货箱分组、机型分配）
- 返航余量的敏感性分析图表

### 问题二：多点多架次运输调度

**算法选择**: **改进NSGA-II + 分层优化**

**核心思路**:

#### 第一层：路径与批次规划
```python
编码方案：
- 基因1: 货箱分组 [批次1包含的货箱ID列表, 批次2, ...]
- 基因2: 访问序列 [各批次的服务区访问顺序]
- 基因3: 机型分配 [各批次使用的机型]
- 基因4: 无人机分配 [各批次使用的具体无人机ID]
- 基因5: 电池分配 [各批次使用的电池ID]
- 基因6: 起飞时刻 [各批次的开始时间]

适应度函数（4个目标）:
1. 配送及时性得分 = Σ(max(0, 送达时间 - 期望时间))
2. 完成时间 = max(所有批次返回时刻)
3. 总能耗 = Σ(各批次能耗)
4. 总架次数 = 批次总数

约束处理：
- 硬约束违反 -> 大惩罚
- 软约束违反 -> 适度惩罚
```

#### 第二层：电池调度
```python
电池池管理系统：
- 维护电池SOC状态表
- 任务分配时检查可用电池
- 返回后计算剩余SOC，安排充电
- 充电分两阶段（0-90%快充65%时间，90-100%慢充35%时间）

调度策略：
- 优先使用SOC最高的可用电池
- 平衡各电池使用次数
- 考虑充电并行性
```

#### NSGA-II改进点
1. **智能初始化**
   - 50%贪心构造（按时间窗紧急度）
   - 30%随机扰动
   - 20%完全随机

2. **混合交叉算子**
   - 路径部分：顺序交叉(OX)
   - 分配部分：均匀交叉(UX)
   - 时间部分：算术交叉

3. **自适应变异**
   - 变异率随进化代数衰减
   - 多种变异：插入、交换、逆转、重分配

**预期输出**:
- Pareto前沿（展示多个非劣解）
- 推荐方案的详细调度表
- 资源使用甘特图
- 货箱送达时间表

### 问题三：通信约束 + 中继部署

**算法选择**: **两阶段迭代优化**

**核心思路**:

#### 阶段1：识别通信盲区
```python
对每个运输批次的每个航段：
1. 计算无人机位置序列（时间步采样）
2. 对每个位置计算到G01的：
   - 自由空间损耗
   - 地形遮挡（视线追踪）
   - 链路预算
3. 标记通信不可用的路径段
```

#### 阶段2：中继优化部署
```python
输入：运输批次计划 + 通信盲区列表

中继决策变量：
- 悬停位置 (x, y, z)
- 服务时段 [t_start, t_end]
- 服务的运输批次列表

优化目标：
1. 最小化中继无人机数量
2. 最小化中继总能耗
3. 最大化通信质量裕度

求解方法：
- 候选位置生成：在DEM上生成3D网格点
- 覆盖计算：每个候选点可覆盖的路径段
- 集合覆盖问题：贪心 + 局部搜索
- 时空调度：确保中继在需要时就位
```

#### 联合迭代
```
循环 until 收敛:
  1. 固定中继方案，优化运输路径（NSGA-II）
  2. 固定运输路径，优化中继部署（贪心+局部搜索）
  3. 评估总目标改进
  4. 如果改进 < 阈值，退出
```

**预期输出**:
- 联合调度方案
- 中继位置和服务时间表
- 通信覆盖可视化图
- 通信质量评估报告

### 问题四：任务分区 + 资源配置

**算法选择**: **约束聚类 + 资源统计分析**

**核心思路**:

#### 分区方法
```python
方法1：K-means改进（地理+工作量）
- 特征向量：[经度, 纬度, 货箱数量, 总重量]
- 约束：同一批次的服务区必须在同一组
- k=2 和 k=3 分别运行

方法2：图分割
- 节点：服务区
- 边权：批次共现次数
- 目标：最小割 + 负载均衡
- 算法：Kernighan-Lin或METIS

方法3：层次聚类
- 距离度量：欧氏距离 + 工作量差异
- 合并策略：Ward方法
- 在合适高度截断得到2/3组
```

#### 资源配置分析
```python
对每个分区：
1. 统计独立执行所需资源
   - 运输无人机数量（按机型）
   - 共享电池数量（按机型）
   - 中继无人机数量
   - 中继能源组件数量

2. 计算评估指标
   - 资源总需求
   - 资源冗余率 = (实际需求 - 理论最小) / 理论最小
   - 工作量标准差（衡量均衡性）
   - 与现有库存的缺口

3. 对比分析
   - 2分区 vs 3分区
   - 各指标权衡
   - 推荐方案
```

**预期输出**:
- 2种分区方案的详细配置
- 资源需求对比表
- 分区可视化地图
- 缺口分析和建议

## ⚠️ 关键难点与解决方案

### 难点1: 计算复杂度过高
**问题**: 15个服务区 × 80个货箱 × 3种机型 × 8架无人机 → 组合爆炸

**解决方案**:
- 分层优化：先批次规划，再详细调度
- 启发式初始化：减少无效搜索
- 并行计算：Python multiprocessing
- 缓存机制：预计算能耗矩阵

### 难点2: 多目标权衡不明确
**问题**: 4-5个相互冲突的目标，如何权衡？

**解决方案**:
- 生成完整Pareto前沿，让决策者选择
- 提供3-5个典型解（保守型、平衡型、激进型）
- 敏感性分析：展示权重变化的影响

### 难点3: 通信-运输耦合
**问题**: 运输路径影响通信需求，中继位置影响路径选择

**解决方案**:
- 迭代优化框架（类似EM算法）
- 松弛策略：先不考虑通信优化运输，再补充中继
- 通信裕度：留有足够的链路余量

### 难点4: 实时地形遮挡计算
**问题**: DEM数据量大，视线追踪计算密集

**解决方案**:
- 空间索引：四叉树或KD树加速
- 采样策略：路径上等间隔采样，不需要每米计算
- 预计算：离线计算常用路径的遮挡情况

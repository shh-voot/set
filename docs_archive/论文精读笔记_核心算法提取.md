## 📖 论文01: 灾后无人机-车辆协同路径优化 (02号文献)

### 基本信息
- **标题:** A Robust Optimization Framework for Two-Echelon Vehicle and UAV Routing
- **来源:** ArXiv 2022
- **适用场景:** 飓风后波多黎各救援 (与华为杯D题高度相似)

### 核心问题定义

**Two-Echelon VRP (2EVRP):**
- **第一层:** 卡车从仓库到卫星站点
- **第二层:** 无人机从卫星站点到受灾社区

**关键假设 (与D题对照):**
1. ✅ 通信基础设施失效 → 需求不确定
2. ✅ 地面交通受阻 → 无人机配送
3. ✅ 多个调度中心 (卫星站) → 多depot
4. ✅ 有限的无人机数量和电池

### 数学模型框架

**图论表示:**
```
G(V, E):
  V = {0} ∪ S ∪ C
    - 0: 仓库/调度中心
    - S: 卫星站点集合 (中转站)
    - C: 受灾社区集合 (服务区)
  
  E = E_t ∪ E_d
    - E_t: 卡车可用边
    - E_d: 无人机可用边
```

**决策变量:**
1. x_ij: 无人机是否使用边 (i,j)
2. y_s: 是否使用站点 s
3. z_sr: 无人机是否从站点s使用路线r
4. q_sc: 从站点s到社区c的配送量

**目标函数 (多目标):**
```
min: 
  α₁ × (总行驶时间) + 
  α₂ × (最大服务延迟) + 
  α₃ × (未满足需求惩罚)
```

### 实验结果 (对标指标)

**与确定性模型对比:**
- 成本降低: 16-20%
- 最大服务延迟: 减少19-40%
- 鲁棒性: 在需求变化±30%时仍保持可行

**计算时间:**
- 小规模 (5站点, 20社区): < 5分钟
- 中规模 (10站点, 50社区): 10-30分钟

## 📖 论文03: 无缺货电池调度 (06号文献)

### 关键约束: 永不缺货

**电池库存跟踪:**
```python
def battery_inventory(t):
    """时刻t的可用电池数量"""
    available = 0
    
    for battery in all_batteries:
        if battery.state == IDLE and battery.soc >= 0.95:
            available += 1
    
    return available

# 约束: 任何时刻都不缺货
# ∀t: battery_inventory(t) >= demand_at_time(t)
```

### 两阶段充电模型

**快充阶段 (0% → 80%):**
- 功率: P_max
- 时间: t₁ = 0.8 × E_capacity / (P_max × η)

**涓流充电阶段 (80% → 100%):**
- 功率: P_max × taper_rate (线性衰减, taper_rate ∈ [0.3, 0.5])
- 时间: t₂ = 0.2 × E_capacity / (P_max × avg_taper × η)

**充电时间计算函数:**
```python
def charging_time(soc_start, soc_target, capacity_kwh, power_kw):
    FAST_THRESHOLD = 0.80
    TAPER_RATE = 0.4  # 涓流阶段平均功率比例
    EFFICIENCY = 0.85  # 充电效率
    
    energy_needed = capacity_kwh * (soc_target - soc_start)
    
    if soc_target <= FAST_THRESHOLD:
        # 全程快充
        return energy_needed / (power_kw * EFFICIENCY)
    
    elif soc_start >= FAST_THRESHOLD:
        # 全程涓流
        avg_power = power_kw * (1 + TAPER_RATE) / 2
        return energy_needed / (avg_power * EFFICIENCY)
    
    else:
        # 跨越两阶段
        fast_energy = capacity_kwh * (FAST_THRESHOLD - soc_start)
        taper_energy = capacity_kwh * (soc_target - FAST_THRESHOLD)
        
        t_fast = fast_energy / (power_kw * EFFICIENCY)
        t_taper = taper_energy / (power_kw * TAPER_RATE * EFFICIENCY)
        
        return t_fast + t_taper
```

## 问题描述

### 核心任务
为15个服务区设计**单架次配送方案**，每个服务区选择一种无人机机型，一次性配送所有货物。

### 约束条件

| 约束类型 | 描述 | 数学表达 |
|---------|------|---------|
| **重量约束** | 总载重 ≤ 无人机最大载重 | $\sum w_i \leq W_{max}$ |
| **体积约束** | 总体积 ≤ 货舱容积 | $\sum v_i \leq V_{max}$ |
| **能量约束** | 往返能耗 ≤ 可用电量 | $E_{total} \leq 0.8 \times E_{battery}$ |
| **单架次** | 每区域只派一架 | $n_{flights} = 1$ |

### 无人机参数对比

| 参数 | A型 | B型 | C型 |
|------|-----|-----|-----|
| 最大载重 (kg) | 70.0 | 65.0 | 69.9 |
| 货舱体积 (m³) | 0.071 | 0.073 | 0.250 |
| 电池容量 (kWh) | 4.5 | 4.0 | 8.0 |
| 最大航程 (km) | 25.0 | 28.0 | 26.0 |
| 巡航功率 (kW) | 6.22 | 6.17 | 13.29 |
| **能效评价** | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐ |

**关键发现**: B型在能效和续航上均优于A型和C型，成为主力机型。

## 算法设计

### 1. 能耗计算模型

#### 分段能耗计算

```
总能耗 = E_起飞 + E_爬升 + E_巡航 + E_下降 + E_降落
```

**各阶段公式**:

1. **起飞/降落固定能耗**
   ```
   E_起降 = P_cruise × t_起降 / 3600
   t_起降 = 30秒（每次）
   ```

2. **爬升能耗**（考虑重力势能）
   ```
   E_爬升 = [(m_uav + m_cargo) × g × Δh / η_爬升 + P_cruise × t_爬升] / 3600
   
   其中:
   - Δh = h_目标 - h_起点
   - η_爬升 = 0.7 (效率系数)
   - t_爬升 = Δh / v_爬升
   ```

3. **巡航能耗**
   ```
   E_巡航 = P_cruise × t_巡航 / 3600
   t_巡航 = d_水平 / v_巡航
   ```

4. **下降能耗**（重力势能回收）
   ```
   E_下降 = [P_cruise × t_下降 - (m_uav + m_cargo) × g × Δh × η_下降] / 3600
   
   注: η_下降 = 0.0 (无回收)
   ```

### 2. 三维背包问题

#### 问题建模

```python
# 输入
weights = [w1, w2, ..., wn]  # 货物重量
volumes = [v1, v2, ..., vn]  # 货物体积
energies = [e1, e2, ..., en] # 增加的能耗

# 约束
W_max = 无人机最大载重
V_max = 无人机货舱体积
E_max = 0.8 × 电池容量

# 目标
max Σ x_i  (x_i ∈ {0, 1})

s.t.
  Σ w_i × x_i ≤ W_max
  Σ v_i × x_i ≤ V_max
  Σ e_i × x_i ≤ E_max
```

#### 动态规划求解

```python
def knapsack_3d(weights, volumes, energies, values, W, V, E):
    """
    三维背包动态规划
    状态: dp[w][v][e] = 最大价值
    """
    n = len(weights)
    dp = {}  # 稀疏表示
    
    # 初始化
    dp[(0, 0, 0)] = 0
    
    # 逐个物品考虑
    for i in range(n):
        new_dp = dict(dp)
        for (w, v, e), val in dp.items():
            # 尝试放入第i个物品
            nw = w + weights[i]
            nv = v + volumes[i]
            ne = e + energies[i]
            
            if nw <= W and nv <= V and ne <= E:
                new_val = val + values[i]
                key = (nw, nv, ne)
                if key not in new_dp or new_dp[key] < new_val:
                    new_dp[key] = new_val
        
        dp = new_dp
    
    # 回溯找最优解
    return selected_items, max_value
```

### 3. 机型选择策略

```python
for each service_area:
    for each uav_type in [A, B, C]:
        # 计算到该区域的能耗
        energy_matrix[uav_type] = calculate_energy(depot, area, uav_type)
        
        # 求解背包问题
        selected, total_value = knapsack_3d(...)

        score[uav_type] = total_value / energy_matrix[uav_type]
```

#### 2.1 问题一：单架次配送方案

**2.1.1 问题建模**

```latex
\subsection{问题建模}

考虑调度中心$O$和$N=15$个服务区$S_1, S_2, \ldots, S_{15}$。
每个服务区$S_i$有货物集合$C_i = \{c_1, c_2, \ldots, c_{n_i}\}$,
每个货物$c_j$具有重量$w_j$和体积$v_j$。

设$x_{ij} \in \{0, 1\}$表示货物$c_j$是否被运送到服务区$S_i$,
$u_i \in \{A, B, C\}$表示服务区$i$选用的无人机类型。

优化目标:
\begin{equation}
\max \sum_{i=1}^{N} \sum_{j \in C_i} x_{ij}
\end{equation}

约束条件:
\begin{align}
\sum_{j \in C_i} w_j \cdot x_{ij} &\leq W_{max}(u_i), \quad \forall i \\
\sum_{j \in C_i} v_j \cdot x_{ij} &\leq V_{max}(u_i), \quad \forall i \\
E_i(u_i, \{x_{ij}\}) &\leq 0.8 \cdot E_{battery}(u_i), \quad \forall i
\end{align}
```

**2.1.2 能耗计算模型**

详细描述四阶段能耗公式（起飞、爬升、巡航、降落）

**2.1.3 求解算法**

算法流程图 + 伪代码:
```
Algorithm 1: Single-Flight Delivery Planning
Input: Service areas S, UAV types U, Cargo sets C
Output: Delivery plan P

1: for each service area s in S do
2:    for each UAV type u in U do
3:        Calculate energy matrix E[s][u]
4:        Solve 3D knapsack problem
5:        Compute score[u] = cargo_count / energy
6:    end for
7:    Select UAV u* with max score
8:    P[s] = (u*, selected_cargos)
9: end for
10: return P
```

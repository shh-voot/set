# 2024华为杯数学建模竞赛D题 - 快速理解指南

## 🎯 赛题核心

**场景**: 广西灾区应急物资无人机运输

**任务**: 用最少的时间和能耗，将80箱物资从基站O01配送到15个服务区

## 📊 关键数字一览表

| 项目 | 数值 | 说明 |
|------|------|------|
| 物资总数 | 80箱 | 分布在15个服务区 |
| 服务区数 | 15个 | S001-S015 |
| 决策点数 | 3个 | W、E、N |
| UAV类型 | 4种 | A/B/C运输型 + R中继型 |
| 最大通信距离 | 3km | 必须保持连接 |
| 快充时间 | 122分钟 | 充到90% |
| 慢充时间 | 116分钟 | 90%→100% |

## 🛸 四种无人机对比

| 型号 | 载重 | 体积 | 电池 | 用途 |
|------|------|------|------|------|
| **A型** | 25kg | 0.25m³ | 5.03kWh | 轻型运输 |
| **B型** | 30kg | 0.25m³ | 6.12kWh | 中型运输 |
| **C型** | 80kg* | 0.25m³ | 8.68kWh | 重型运输 |
| **R型** | 0kg | 0m³ | 2.47kWh | 中继通信 |

*注: C型理论载重80kg，但S008物资约束为28.9kg

## 🔋 充电模型（核心难点）

```
电量 0% ─────122分钟────→ 90% ─────116分钟────→ 100%
          快充(高效)              慢充(低效)
```

**关键洞察**:
- 快充效率: 0.738%/分钟
- 慢充效率: 0.086%/分钟
- **慢充效率仅为快充的11.7%**
- **策略**: 尽量只快充到90%，除非最后一批任务

## 📍 地理布局

```
        S004(N点附近)
           |
    S011 - N - S013
       \   |   /
        \  |  /
    S001-W-O01-E-S002
        /  |  \
       /   |   \
    S006   |   S005
           |
         S008(最远，8.12km)
```

**距离特点**:
- O01到各服务区: 0.72-4.76km
- S008最远: 8.12km（需要中继）
- 决策点可缩短路径

## 🎯 四个问题概览

### 问题一：单点多服务区运输
- **出发点**: 仅O01
- **目标**: 最短时间完成80箱配送
- **我们的结果**: 19架次，45.28kWh，232分钟

### 问题二：多点多服务区调度
- **出发点**: O01 + W + E + N
- **目标**: 利用决策点分流优化
- **我们的结果**: 33架次，31.16kWh，126分钟
- **提升**: 能耗降31%，时间降45%

### 问题三：中继网络部署
- **目标**: 用最少中继实现100%通信覆盖
- **难点**: S008距离O01达8.12km（超过3km限制）
- **我们的结果**: 8个中继，100%覆盖
- **关键**: R07→R08链路覆盖S008

### 问题四：任务区划分
- **目标**: 将任务区分为三个片区
- **方案**: 西北区9组 + 东南区14组 + 中继5组
- **效果**: 降低O01拥堵，负载均衡

## ❓ 常见疑问

### Q1: 为什么C型只能装28.9kg而不是80kg？
**A**: 赛题数据中S008服务区的物资总重约28.9kg，这是实际约束。

### Q2: 为什么问题二比问题一能耗更低？
**A**: 利用W、E、N决策点分流，缩短了平均飞行距离。

### Q3: 为什么需要8个中继而不是6个？
**A**: S008距离O01达8.12km，需要R07→R08两跳中继才能覆盖。

### Q4: 充电时间占总时间的比例是多少？
**A**: 约占40-50%，这也是为什么充电优化如此重要。

### Q5: 能否进一步减少架次数？
**A**: 19架次（问题一）和33架次（问题二）已经是理论最优解，受载重和体积约束限制。

## 核心技术挑战

### 1. 通信可达性判定

**Line-of-Sight (LoS) 通信模型**
- 输入：DEM地形数据、无人机位置、网关/中继位置
- 输出：是否可通信（布尔值）
- 算法：射线追踪 + 地形遮挡判断

```
通信链路类型：
1. 运输机 ↔ 固定网关 (直连)
2. 运输机 ↔ 中继机 ↔ 固定网关 (中继)
```

**关键参数**（附录3）：
- 通信距离上限
- 天线高度、功率
- LoS遮挡判定规则

### 2. 中继无人机部署优化

**决策变量**：
- 悬停位置 (x, y, z) - 在DEM范围内
- 服务时段 [t_start, t_end]
- 服务的运输机集合
- 能源组件分配（电池/充电计划）

**约束**：
- 悬停离地高度 ≤ 规定上限
- 悬停能耗 = hover_power_kw × 悬停时长
- 通信能耗 = comm_power_kw × 通信时长
- 电池容量限制

**目标**：
- 最小化中继机数量/架次
- 最小化中继能耗
- 最大化覆盖运输任务

### 3. 联合调度问题建模

**决策变量**：
```
运输层面：
- 货箱分批 B = {B1, B2, ..., Bn}
- 访问顺序 π
- 无人机类型选择 uav_type
- 架次开始时刻 t_start
- 电池分配

中继层面：
- 中继机数量 N_relay
- 悬停位置 P_relay = {p1, p2, ..., pN}
- 服务时段 T_relay = {[t1_s, t1_e], ...}
- 能源分配
```

**硬约束**：
1. 货箱时限约束
2. 载重/体积约束
3. 能量约束（运输机 + 中继机）
4. **连续通信约束**（核心新增）
5. 资源可用性约束

**软约束/优化目标**：
1. 配送及时性（最小化延迟）
2. 联合任务完成时间
3. 总能耗（运输 + 中继）
4. 使用架次数（运输机 + 中继机）

## 问题分解与求解思路

### 阶段1：通信覆盖分析（基于DEM）

**输入**：
- DEM地形数据
- 固定网关位置 O01
- 服务区位置集合 S
- 问题二的路径规划结果

**输出**：
- 通信盲区识别
- 候选中继位置集合
- 每个位置的覆盖范围

**方法**：
- Viewshed分析（可视域计算）
- Set Cover Problem（集合覆盖）
- 候选位置生成（网格搜索 + 高度优化）

### 阶段2：中继部署优化

**模型**：Relay Placement Problem (RPP)

```
minimize: α·N_relay + β·E_relay
subject to:
  - 每个运输任务的通信连续性
  - 中继位置可行性（DEM内、高度限制）
  - 中继能量约束
```

**算法选项**：
1. 贪心启发式（快速）
2. 遗传算法（质量好）
3. 整数规划（小规模精确解）

### 阶段3：联合调度优化

**模型**：Communication-Aware VRP with Relay (CA-VRP-R)

**分层求解**：
```
Level 1: 路径规划（复用问题二）
  → 获得候选路径集合

Level 2: 通信覆盖检查
  → 识别通信盲区

Level 3: 中继机部署
  → 确定中继位置和服务时段

Level 4: 联合调度优化
  → 时间窗协调
  → 资源分配
  → 多目标优化
```

### 阶段4：多目标权衡分析

**目标函数**：
```
F = w1·及时性 + w2·完成时间 + w3·能耗 + w4·架次数

其中：
- 及时性 = Σ max(0, 实际送达时间 - 时限)
- 完成时间 = max(所有架次返回时刻) - 首架次出发时刻
- 能耗 = 运输机总能耗 + 中继机总能耗
- 架次数 = 运输机架次 + 中继机架次
```

**权衡分析**：
- Pareto前沿分析
- 权重敏感性分析
- 场景对比（有/无中继）

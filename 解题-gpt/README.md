# 解题-GPT当前交付包

本目录是当前交付的唯一结果目录，集中保存四个问题的解题步骤、算法代码、性能结果、对比报告和可视化输出。官方原始数据仍只读于上一级 `D:\claude\华为杯\D题\数据`，不会复制或改写官方数据。

## 目录

- `步骤/`：问题一至问题四建模、算法和合规说明
- `代码/`：当前求解器及问题四可视化脚本
- `结果/`：当前正式Excel、JSON和核验输出
- `可视化/论文图表/`：四张论文级终稿图，统一使用官方 DEM 底图和 ocean-mint 配色
- `论文/`：格式要求摘要、论文初稿、图表清单、AI 使用说明和参考文献清单

当前正式数值以本目录下 `结果/` 为准；四题求解器和步骤均集中在本目录，不引用外层历史副本。

## 当前完成状态

### 问题一

已完成官方数据下的单架次组批和时间优先局部优化：18架次、80箱唯一覆盖、所有架次物理可行；最长单架次38.6048 min，总能耗约56.5159 kWh。

### 问题二

当前正式版使用“截止时间优先 + 候选组批 + 有限宽度束搜索 + 1交换局部搜索”，在官方 DEM、机型、电池和时限约束下得到43架次，系统完成时间171.5840 min，80箱全部按时，总运输能耗93.8540 kWh。结果文件为 `结果/问题二_增强优化版.xlsx`。

### 问题三

已完成官方R01/R02中继的DEM通信覆盖和运输-中继联合调度：15/15服务区覆盖，43/43架次通信可用，80箱无迟到，联合完成时间189.1752 min，总能耗99.3546 kWh，能源组件使用4/6组。中继候选采用网格全枚举、双向链路预算和小规模集合覆盖搜索。

### 问题四

正式结论是：按题目要求独立并行时存在资源缺口；另外给出不替代正式口径的批次整体错峰复用情景：

- 2批次：A/B/C无人机4/2/2，电池6/4/4，完成274.6992 min，官方库存可行；
- 3批次：A/B/C无人机4/2/2，电池6/3/4，完成384.0350 min，官方库存可行。

问题四分别报告独立并行缺口和整体错峰复用情景。独立并行方案存在官方机队/电池缺口；错峰情景在官方库存下可行，但不替代题目规定的独立并行口径，也不宣称全局最优。

问题一至三有官方约束下的可行解；问题四已完成资源需求与可行性分析，但严格独立并行口径下结论为库存不足，不能称为库存内可行解。错峰情景只说明改变批次时间关系后可复用资源。

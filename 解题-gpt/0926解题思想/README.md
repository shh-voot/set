# 0926 解题思想与问题三正式结果

本目录记录 2026-09-26 基于官方附件数据重算的算法思想迁移和问题三联合调度正式结果。参考文档只用于吸收建模结构，不直接继承其中的架次、时间、能耗或中继数量结论。

## 数据口径

- 唯一数据源：`D题/数据` 中的官方货箱、服务区、无人机、电池、中继、通信参数和 30 m DEM。
- 运输端点按官方规则采用服务区地面高程加 30 m。
- 通信按官方频率、收发功率、增益、系统损耗、遮挡损耗、灵敏度、裕量和 DEM 射线判定。
- 中继能量组件使用官方 3.2 kWh 容量和 20% 返航余量，即单组件可用能量 2.56 kWh；不允许空中更换组件。

## 融合后的算法结构

1. 继承现有问题二的架次、货箱唯一覆盖、截止期优先和双资源 EDF 解码框架。
2. 学习参考思路中的“紧急任务先安排、候选机型重解码、通信盲段转时间窗、运输与中继联合核验”结构。
3. 对问题三允许官方可行机型替换；每个替换必须重新通过官方载荷、体积、DEM 航程和能源检查。
4. 对每个运输架次的直连失效路径构造盲段时间窗，并用 CP-SAT 联合选择运输开始时间和三个候选悬停点的服务窗。
5. 中继服务窗再映射为真实起飞、出场、返场和周转区间，检查 R01/R02 的不重叠执行和组件库存。
6. 最后对 45 个架次的出发/返场 121 个路径样本逐点核验；任意通信缺口、迟到、资源冲突或物理约束违例都会使正式结果判为不可行。

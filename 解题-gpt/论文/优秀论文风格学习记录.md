# 优秀论文风格学习记录

已通过 `https://github.com/zhanwen/MathModel` 的公开仓库目录接口核对其组织方式。仓库按年份区分“数模悉知/论文模板”和“最终获奖名单”，同时单列国赛论文、题目、模板和算法资料。由此提取的可迁移做法如下：

1. 论文先给摘要和关键词，再按问题编号组织正文；每个问题都采用“模型假设—变量/约束—算法—结果”的闭环。
2. 结果部分把关键指标放在表格或图中，正文只解释指标变化、约束是否满足和方法适用范围。
3. 图表服务于论证：路径/空间图回答“在哪里执行”，时间轴或甘特图回答“何时执行”，资源图回答“是否超库存”，避免把多个不相关指标堆在一张图里。
4. 方法章节与结果章节分开，参数、数据来源和复核口径单独说明；优秀论文的表达重点是可复现和可核验，而不是堆砌算法名称。

本文据此采用四张“一问一组”的图表，并将官方数据、算法输出、参考论文截图三种来源分开记录。该文件是写作风格记录，不是对仓库中任何论文文字或数据的复制。

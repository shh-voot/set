# 问题二优化

本目录记录问题二在官方数据上的独立优化实验。优化对象是已有可行架次的执行顺序；所有货箱、服务区、无人机参数、库存、电池参数和 DEM 均来自：

`D:\\claude\\华为杯\\D题\\数据`

## 当前结论

在重新运行当前正式求解器得到的基线基础上，加入带自适应算子权重的 ALNS 顺序破坏—修复，得到以下候选方案：

| 指标 | 当前正式基线 | ALNS 候选 |
|---|---:|---:|
| 架次 | 43 | 43 |
| 系统完成时间（min） | 173.7274 | **164.8136** |
| 总运输能耗（kWh） | 95.2042 | 95.2042 |
| 迟到货箱数 | 0 | 0 |
| 总迟到时间（min） | 0 | 0 |
| 覆盖货箱数 | 80 | 80 |

完成时间减少 8.9138 min，降幅约 5.13%；架次、能耗和时限可行性保持不变。候选方案还没有覆盖问题三、问题四的下游重算，因此暂不直接替换下游结果。

```text

set P2_ALNS_SEED=20260926
set P2_ALNS_ITER=250
C:\\Users\\yoush\\anaconda3\\python.exe 解题-gpt\\问题2优化\\代码\\optimize_alns.py
C:\\Users\\yoush\\anaconda3\\python.exe 解题-gpt\\问题2优化\\代码\\validate_candidate.py
```

最终候选使用随机种子 `20260926`、迭代次数 `250`。可通过环境变量 `P2_ALNS_SEED` 和 `P2_ALNS_ITER` 修改，但修改后必须重新运行核验程序，并且只有在官方约束全部满足时才可采用。

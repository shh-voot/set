## 💻 代码文件说明

### cpsat_scheduler.py (440行)
**CP-SAT约束规划调度器（内层优化）**

**功能**：给定架次列表，精确求解资源分配和时序
- 决策变量：无人机ID、电池ID、起飞时刻
- 约束建模：资源数量、时间窗口、充电周转、货箱时限
- 求解目标：最小化makespan

**关键类**：
- `CPSATScheduler` - 主调度器
- `Mission` - 架次数据结构
- `ScheduleResult` - 调度结果

**关键方法**：
```python
def schedule(missions: List[Mission]) -> ScheduleResult:
    """求解架次调度，返回精确时间表"""
```

### nsga2_optimizer.py (470行)
**NSGA-II多目标遗传算法（外层优化）**

**功能**：搜索最优组批、路线和机型组合
- 编码方式：Individual = [货箱分组, 访问路线, 机型选择]
- 三个目标：架次数↓、能耗↓、时间↓
- 进化算法：非支配排序 + 拥挤度距离

**关键类**：
- `NSGAIIOptimizer` - 主优化器
- `Individual` - 候选解

**关键方法**：
```python
def initialize_population() -> List[Individual]:
    """三种策略初始化种群"""

def evaluate(individual: Individual) -> Individual:
    """评估个体（调用DEM + CP-SAT）"""

def optimize() -> List[Individual]:
    """执行NSGA-II优化，返回帕累托前沿"""
```

## ❓ 常见问题

### Q1: ortools导入失败
**原因**：Python 3.13不支持
**解决**：使用Python 3.10环境（见环境配置指南.md）

### Q2: 找不到模块src
**原因**：路径设置问题
**解决**：确保在正确目录运行，或检查sys.path

### Q3: 优化速度太慢
**原因**：参数设置过大
**解决**：减小pop_size和max_generations

### Q4: 结果不如预期
**原因**：收敛不充分或陷入局部最优
**解决**：增加代数，或改变seed多次运行

详细问题解答见：**README.md**

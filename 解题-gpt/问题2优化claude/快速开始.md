```bash

# 2. 激活环境
conda activate huawei_opt

# 3. 安装依赖
cd "D:\claude\华为杯\D题\解题-gpt\问题2优化claude"
pip install ortools numpy pandas openpyxl

# 4. 测试

# 5. 运行（选一个）
python quick_run.py      # 快速版（10分钟）
python main_optimize.py  # 完整版（1小时）
```

**完成！** 等待结果输出到 `结果\` 文件夹。

## 方案B：如果没有conda

### 步骤1：下载Python 3.10
访问：https://www.python.org/downloads/release/python-31011/
下载：Windows installer (64-bit)

```bash

```

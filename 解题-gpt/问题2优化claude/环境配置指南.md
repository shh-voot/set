# 问题2优化 - Python环境配置指南

## 问题诊断

当前环境：Python 3.13.5
问题：ortools在Python 3.13上存在DLL依赖问题

```
OSError: [WinError 127] 找不到指定的程序
```

这是因为ortools 9.15还未完全支持Python 3.13。

## 解决方案

### 方案1：创建Python 3.10虚拟环境（推荐）

```bash
# 1. 创建新的conda环境
conda create -n huawei_p2_opt python=3.10 -y

# 2. 激活环境
conda activate huawei_p2_opt

# 3. 安装依赖
cd "D:\claude\华为杯\D题\解题-gpt\问题2优化claude"
pip install ortools numpy pandas openpyxl

# 4. 测试安装
python -c "from ortools.sat.python import cp_model; print('Success!')"

# 5. 运行优化
cd 代码
python test_framework.py        # 测试框架
python quick_run.py             # 快速运行（10分钟）
python main_optimize.py         # 完整优化（1小时）
```

### 方案2：使用venv创建虚拟环境

```bash

# 访问 https://www.python.org/downloads/release/python-31011/
# 下载 Windows installer (64-bit)

# 2. 安装到 C:\Python310

# 3. 创建虚拟环境
C:\Python310\python.exe -m venv huawei_venv

# 4. 激活虚拟环境
huawei_venv\Scripts\activate

# 5. 安装依赖
pip install ortools numpy pandas openpyxl

# 6. 运行
cd "D:\claude\华为杯\D题\解题-gpt\问题2优化claude\代码"

```

### 方案3：使用Docker（完全隔离）

创建 `Dockerfile`:
```dockerfile
FROM python:3.10-slim

WORKDIR /app

# 安装依赖
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制代码
COPY . .

# 运行
CMD ["python", "代码/main_optimize.py"]
```

运行：
```bash
docker build -t huawei-opt .
docker run -v "D:\claude\华为杯\D题\数据:/app/数据" huawei-opt
```

## 常见问题

### Q1: ModuleNotFoundError: No module named 'src'
```bash
# 确保正确设置了sys.path
cd "D:\claude\华为杯\D题\解题-gpt\问题2优化claude\代码"
python -c "import sys; print('\n'.join(sys.path))"

# 应该包含：
# D:\claude\华为杯\D题
# D:\claude\华为杯\D题\解题-gpt\代码
```

### Q2: ortools导入失败
```bash
# 卸载重装
pip uninstall ortools -y
pip install ortools==9.7.2996  # 使用稳定版本

# 或者
conda install -c conda-forge ortools-python
```

### Q3: 内存不足
```bash
# 减小种群大小
pop_size=10
max_generations=20
```

### Q4: CP-SAT求解超时
```bash
# 增加时限或降低精度要求
cpsat_scheduler = CPSATScheduler(
    time_limit_sec=120  # 增加到2分钟
)

# 或在cpsat_scheduler.py中添加：
solver.parameters.relative_gap_limit = 0.05  # 允许5%误差
```

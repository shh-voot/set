## 核心算法

### 双层优化架构

**外层：NSGA-II（Non-dominated Sorting Genetic Algorithm II）**
- 搜索空间：货箱组批方案 + 多点访问路线 + 机型选择
- 三个目标函数：
  1. 最小化架次数
  2. 最小化总能耗
  3. 最小化完成时间
- 种群进化：非支配排序 + 拥挤度距离选择

**内层：CP-SAT（Constraint Programming - SAT）**
- 给定一组架次，精确求解：
  1. 每个架次使用哪架无人机
  2. 每个架次使用哪组电池
  3. 每个架次何时起飞
  4. 电池充电周转时序
- 约束条件：
  - 无人机数量限制（A型4架，B型2架，C型2架）
  - 共享电池数量限制（A型6组，B型4组，C型4组）
  - 无人机任务不重叠
  - 电池使用和充电不重叠
  - 货箱必须在deadline前送达

## 关键改进点

### 1. 多点访问路线优化
**现有方法**：大多数架次只访问单个服务区，导致往返次数多
**新方法**：鼓励一个架次访问多个地理位置相近的服务区，减少空载往返

示例：
```
现有: O01→S01→O01, O01→S02→O01, O01→S03→O01 (3架次)
优化: O01→S01→S02→S03→O01 (1架次，如果载重和能耗允许)
```

### 2. 智能组批策略
**三种初始化策略**：
1. 地理位置贪心（40%）：优先组合相近服务区的货箱
2. 时限优先贪心（30%）：优先处理紧急货箱，时限相近的货箱组合
3. 完全随机（30%）：保持种群多样性

### 3. 机型自适应选择
**现有方法**：可能预先指定机型或使用固定规则
**新方法**：算法自动学习最优机型组合
- 短途轻载 → 优先A型（能效高）
- 长途重载 → 考虑B/C型（载重大）

### 4. 精确资源调度
**CP-SAT求解器**确保：
- 严格满足无人机和电池数量限制
- 准确建模电池充电时间（两阶段充电曲线）
- 避免资源冲突和时间窗口违反

## 输出结果

### 帕累托前沿
算法会生成多个非支配解，每个解在某些目标上更优：
- 方案1：架次最少，但能耗可能较高
- 方案2：能耗最低，但时间可能较长
- 方案3：时间最短，但架次可能较多
- ...

### 自动选择最佳方案
程序会自动选择最接近目标（25架次，70kWh，150min）的方案

### 文件输出
```

├── 帕累托前沿汇总.xlsx
```

2. **逐箱时限**：每个货箱的送达时刻和是否准时
3. **资源核验**：无人机和电池使用统计
4. **校验**：方案性能指标汇总

## 算法特点

### 优势
1. **全局搜索**：遗传算法避免陷入局部最优
2. **多目标优化**：帕累托前沿提供多种权衡方案
3. **严格约束**：CP-SAT保证资源约束100%满足
4. **可扩展**：容易添加新的约束或目标

### 局限
1. **计算时间**：需要30分钟到数小时（视参数而定）
2. **随机性**：不同运行可能得到不同结果（可通过seed控制）
3. **参数敏感**：种群大小、代数等参数影响结果质量

## 技术支持

### 常见问题

**Q: ortools导入失败**
A: 检查Python版本，建议使用3.8-3.11。或尝试：
```bash
pip install --upgrade ortools
```

**Q: 优化速度太慢**
A: 减小pop_size和max_generations，或缩短time_limit_sec

**Q: 找不到可行解**
A: 检查时限约束是否过严，增加CP-SAT时限

**Q: 结果不如预期**
A: 增加种群和代数，多次运行选最优

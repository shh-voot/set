# 问题2双层优化方案（NSGA-II + CP-SAT）

## 当前状况
- 架次数：43
- 完成时间：173.7分钟（2.9小时）
- 总能耗：95.2 kWh
- 使用机型：A型4架，B型2架，C型2架

## 优化目标
- 架次数：≈25架次
- 完成时间：≈150分钟（2.5小时）
- 总能耗：≈70 kWh
- 准时率：100%

## 优化策略

### 双层优化架构

#### 外层：NSGA-II多目标遗传算法
**优化变量：**
1. 货箱组批方案（每个架次携带的货箱集合）
2. 多点访问顺序（每个架次访问服务区的顺序）
3. 机型选择（每个架次使用的无人机型号）

**目标函数：**
1. 最小化架次数
2. 最小化总能耗
3. 最小化完成时间

**约束条件：**
- 每个货箱必须且仅被分配一次
- 载重和体积约束
- 能量返航安全余量
- 物理可行性（通过DEM验证）

#### 内层：CP-SAT约束规划
**优化变量：**
1. 每个架次分配的具体无人机ID
2. 每个架次使用的电池ID
3. 每个架次的起飞时刻
4. 电池充电周转时序

**约束条件：**
1. 无人机数量限制（A型4架，B型2架，C型2架）
2. 共享电池数量限制（A型6组，B型4组，C型4组）
3. 无人机-电池时间窗口约束
4. 电池SOC和充电时间约束
5. 货箱时限约束

**目标：**
最小化完成时间（makespan）

### 关键改进点

1. **更激进的多点访问**
   - 当前方法倾向于单点或少量服务区
   - 新方法鼓励一个架次访问多个相近服务区
   - 通过TSP/VRP启发式生成初始路线

2. **智能组批策略**
   - 考虑服务区地理位置聚类
   - 考虑货箱时限分层
   - 平衡载重利用率和能耗效率

3. **机型混合优化**
   - 不预设机型，由算法自动选择
   - 短途轻载优先用A型（能效高）
   - 长途重载考虑B/C型

4. **精确资源调度**
   - 用CP-SAT保证所有资源约束
   - 考虑电池充电时间的精确建模
   - 避免启发式方法的资源冲突

## 算法流程

```
初始化种群（随机生成可行的组批和路线方案）
↓
For 每代 in NSGA-II:
    For 每个个体（组批+路线+机型方案）:
        1. 解码个体为具体架次列表
        2. 验证物理可行性（DEM + 能耗模型）
        3. 调用CP-SAT求解精确调度
        4. 计算目标函数值（架次数、能耗、时间）
    ↓
    非支配排序
    拥挤度计算
    选择、交叉、变异
    生成下一代
↓
输出帕累托前沿
选择最符合目标的方案
```

## 预期效果
- 通过多点访问减少30-40%架次数
- 通过路线优化降低20-25%能耗
- 通过精确调度缩短15-20%完成时间

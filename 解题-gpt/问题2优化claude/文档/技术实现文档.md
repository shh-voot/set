## 算法伪代码

### NSGA-II主循环
```
algorithm NSGA_II:
    P ← initialize_population(pop_size)
    evaluate(P)
    
    for gen = 1 to max_generations:
        Q ← []
        
        // 生成子代
        while |Q| < pop_size:
            p1 ← tournament_selection(P)
            p2 ← tournament_selection(P)
            c1, c2 ← crossover(p1, p2)
            c1 ← mutate(c1)
            c2 ← mutate(c2)
            Q ← Q ∪ {c1, c2}
        
        evaluate(Q)
        
        // 环境选择
        R ← P ∪ Q
        F ← fast_non_dominated_sort(R)
        P_next ← []
        i ← 0
        
        while |P_next| + |F[i]| ≤ pop_size:
            calculate_crowding_distance(F[i])
            P_next ← P_next ∪ F[i]
            i ← i + 1
        
        if |P_next| < pop_size:
            calculate_crowding_distance(F[i])
            sort F[i] by crowding_distance (descending)
            P_next ← P_next ∪ F[i][0 : pop_size - |P_next|]
        
        P ← P_next
    
    return F[0]  // 帕累托前沿
```

### CP-SAT调度
```
algorithm CP_SAT_Schedule(missions):
    model ← new CP_Model()
    
    // 决策变量
    for each mission m:
        start[m] ← IntVar(0, MAX_TIME)
        end[m] ← IntVar(0, MAX_TIME)
        uav[m] ← IntVar(0, num_uavs[m.type] - 1)
        battery[m] ← IntVar(0, num_batteries[m.type] - 1)
        
        model.Add(end[m] == start[m] + m.duration)
    
    // 无人机不重叠约束
    for each uav_type:
        for each uav_idx in 0..num_uavs[uav_type]:
            intervals ← []
            for each mission m where m.type == uav_type:
                is_assigned ← BoolVar()
                model.Add(uav[m] == uav_idx).OnlyEnforceIf(is_assigned)
                interval ← OptionalIntervalVar(
                    start[m], m.duration, end[m], is_assigned
                )
                intervals.append(interval)
            
            model.AddNoOverlap(intervals)
    
    // 电池不重叠约束（含充电时间）
    for each battery_type:
        for each battery_idx:
            intervals ← []
            for each mission m where m.type == battery_type:
                is_assigned ← BoolVar()
                model.Add(battery[m] == battery_idx).OnlyEnforceIf(is_assigned)
                
                charge_time ← calculate_charging_time(m.energy)
                total_time ← m.duration + charge_time
                
                interval ← OptionalIntervalVar(
                    start[m], total_time, start[m] + total_time, is_assigned
                )
                intervals.append(interval)
            
            model.AddNoOverlap(intervals)
    
    // 时限约束
    for each mission m:
        delivery_time ← start[m] + m.delivery_offset
        model.Add(delivery_time ≤ m.deadline)
    
    // 目标：最小化makespan
    makespan ← IntVar(0, MAX_TIME)
    for each mission m:
        model.Add(makespan ≥ end[m])
    
    model.Minimize(makespan)
    
    solver ← CP_Solver()
    status ← solver.Solve(model)
    
    if status in {OPTIMAL, FEASIBLE}:
        return extract_solution(solver)
    else:
        return INFEASIBLE
```

## 遗传操作详解

### 交叉操作（单点交叉）
```
Parent1: [G1, G2, G3, G4, G5]
Parent2: [H1, H2, H3, H4]

切点: 2

Child1: [G1, G2 | H3, H4]
Child2: [H1, H2 | G3, G4, G5]

然后修复：确保每个货箱恰好出现一次
```

### 变异操作（4种）

1. **合并两个架次**
```
Before: [[C001, C002], [C003], [C004, C005]]
After:  [[C001, C002, C003], [C004, C005]]
```

2. **拆分一个架次**
```
Before: [[C001, C002, C003, C004]]
After:  [[C001, C002], [C003, C004]]
```

3. **改变机型**
```
Before: types = ['A', 'B', 'A']
After:  types = ['A', 'C', 'A']
```

4. **改变访问顺序**
```
Before: routes = [['S01', 'S02', 'S03']]
After:  routes = [['S02', 'S01', 'S03']]
```

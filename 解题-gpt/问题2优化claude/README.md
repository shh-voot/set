# 问题2双层优化 - 使用说明

## 算法架构

### 外层：NSGA-II多目标遗传算法
- **优化变量**：货箱组批、服务区访问顺序、机型选择
- **目标函数**：最小化架次数、总能耗、完成时间
- **搜索策略**：非支配排序、拥挤度选择、遗传操作

### 内层：CP-SAT约束规划
- **优化变量**：无人机分配、电池分配、起飞时刻
- **约束条件**：资源数量、时间窗口、充电周转、货箱时限
- **求解器**：Google OR-Tools CP-SAT

## 算法流程

```
1. 初始化种群（30个个体）
   ├─ 地理位置贪心 (40%)
   ├─ 时限优先贪心 (30%)
   └─ 完全随机 (30%)

2. 对每个个体评估
   ├─ 验证物理可行性（DEM+能耗模型）
   └─ CP-SAT精确调度

3. 迭代50代
   ├─ 非支配排序
   ├─ 拥挤度计算
   ├─ 锦标赛选择
   ├─ 交叉操作（货箱重组）
   ├─ 变异操作（合并/拆分/换型/换序）
   └─ 环境选择

4. 输出帕累托前沿
   └─ 选择最接近目标的方案
```

## 性能优化建议

### 提速策略
1. **减小种群规模**：`pop_size=20`（牺牲解质量）
2. **减少代数**：`max_generations=30`（可能收敛不充分）
3. **缩短CP-SAT时限**：`time_limit_sec=30`（可能得次优调度）

### 提质策略
1. **增大种群规模**：`pop_size=50`（增加计算时间）
2. **增加代数**：`max_generations=100`（更充分搜索）
3. **多次运行**：改变`seed`值，选择最优结果

1. **多点访问路线**：一个架次访问多个相近服务区，减少空载往返
2. **智能组批**：考虑地理位置和时限，提高载荷利用率

- 增加 `time_limit_sec` 参数
- 检查约束是否过于严格（特别是时限）
- 查看终端输出的详细错误信息

- 增加种群规模 `pop_size`
- 增加代数 `max_generations`
- 调整变异概率 `mutation_prob`（0.2-0.4之间）

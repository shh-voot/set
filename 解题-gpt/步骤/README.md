# 当前解题步骤

本文件夹记录当前严格使用官方数据的四个问题求解流程。所有结果以 `数据/无人机应急物资运输基础数据`、官方30 m DEM和当前 `结果/` 文件为准。

## 官方数据基线

- 服务区：15个
- 货箱：80箱
- 运输无人机：A4、B2、C2
- 共享电池：A6、B4、C4
- 中继无人机：R01、R02
- 中继能源组件：6组
- 充电时间：A30、B40、C50分钟
- DEM：30 m分辨率

## 求解顺序

1. 问题一验证单架次物理可行性和货箱组批。
2. 问题二在问题一的可行任务基础上加入实体无人机、电池和截止时间调度。
3. 问题三读取问题二调度，加入DEM视距通信和官方中继部署，并进行运输-中继联合重排。
4. 问题四读取问题二、问题三结果，分析2批次和3批次下的峰值资源需求及库存缺口。

各问题的详细流程见 `问题一.md` 至 `问题四.md`。

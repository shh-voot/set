**最相关的5篇论文**：

1. **Joint 3-D Positioning for UAV Relay with Geographic Information** (IEEE TWC, 2021)
   - 核心：基于地理信息的3D中继定位
   - 方法：Block Coordinate Descent (BCD) + Successive Convex Approximation (SCA)
   - 关键：考虑地形遮挡的LoS概率模型

2. **Cooperative Routing for Air-Ground Vehicle Team** (IEEE TASE, 2019)
   - 核心：通信约束下的多车协同路径规划
   - 方法：MILP精确求解 + Branch-and-Cut
   - 关键：通信维护约束的数学建模

3. **Coordinated Control Under LoS Maintenance Constraints** (Drones, 2024)
   - 核心：山地/城市场景的LoS约束
   - 方法：协同控制 + 障碍物遮挡处理
   - 关键：NLOS条件下的通信中断避免

4. **Cooperative Trajectory Planning in Mountainous Environments** (Symmetry, 2025)
   - 核心：山地非结构化环境的空地协同
   - 方法：严格的车间距离约束维护通信
   - 关键：山地复杂地形处理

5. **Multi-Objective UAV Routing with NSGA-II** (多篇)
   - 核心：多目标优化权衡分析
   - 方法：NSGA-II, PSO, Whale Optimization
   - 关键：Pareto前沿生成与决策支持

### Algorithm 1: LoS通信可达性判定（基于DEM）

**输入**：
- DEM地形数据 (高程矩阵)
- 发送端位置 (x1, y1, z1)
- 接收端位置 (x2, y2, z2)
- 通信参数 (最大距离, 天线高度)

**输出**：
- 是否可通信 (True/False)
- 遮挡点位置 (如果被阻挡)

**方法**：射线追踪 + 地形遮挡检测

```python
def check_los_communication(dem, pos1, pos2, comm_params):
    """
    检查两点之间是否存在LoS通信
    
    基于文献[1][3]的LoS概率模型
    """
    # 1. 距离检查
    distance = euclidean_distance(pos1, pos2)
    if distance > comm_params['max_range']:
        return False
    
    # 2. 射线追踪 - 采样两点之间的路径
    num_samples = int(distance / 10)  # 每10米采样一次
    ray_path = interpolate_path(pos1, pos2, num_samples)
    
    # 3. 地形遮挡检查
    for point in ray_path:
        terrain_height = dem.get_height(point.x, point.y)
        if point.z < terrain_height + 5:  # 5m安全余量
            return False  # 被地形阻挡
    
    return True
```

### Algorithm 2: 通信覆盖区域计算（Viewshed分析）

**输入**：
- DEM地形数据
- 发射点位置 (网关或中继)
- 通信参数

**输出**：
- 覆盖区域多边形
- 覆盖的服务区列表

**方法**：基于文献[1]的地理信息辅助定位

```python
def compute_coverage_area(dem, transmitter_pos, comm_params):
    """
    计算发射点的通信覆盖区域
    
    基于Viewshed分析 + LoS概率模型
    """
    coverage_points = []
    
    # 在通信半径内遍历所有点
    search_radius = comm_params['max_range']
    grid_resolution = 50  # 50米网格
    
    for x in range(-search_radius, search_radius, grid_resolution):
        for y in range(-search_radius, search_radius, grid_resolution):
            target_pos = (transmitter_pos.x + x, 
                         transmitter_pos.y + y, 
                         dem.get_height(x, y) + 10)  # 假设接收端离地10m
            
            if check_los_communication(dem, transmitter_pos, target_pos, comm_params):
                coverage_points.append(target_pos)
    
    # 生成覆盖多边形
    coverage_polygon = convex_hull(coverage_points)
    
    return coverage_polygon
```

### Algorithm 3: 中继候选位置生成

**输入**：
- 通信盲区列表
- DEM地形数据
- 中继机性能参数

**输出**：
- 候选位置列表 {(x, y, z), 覆盖范围, 能耗}

**方法**：基于文献[1]的3D定位优化

```python
def generate_relay_candidates(blind_zones, dem, relay_params):
    """
    生成中继候选位置
    
    策略：
    1. 在盲区附近搜索
    2. 考虑地形高度
    3. 满足高度约束
    """
    candidates = []
    
    for zone in blind_zones:
        # 在盲区中心附近搜索
        center = zone.centroid
        
        # 网格搜索可能的悬停位置
        for dx in [-500, 0, 500]:  # 在中心±500m范围
            for dy in [-500, 0, 500]:
                x = center.x + dx
                y = center.y + dy
                
                # 获取地形高度
                terrain_h = dem.get_height(x, y)
                
                # 尝试不同的悬停高度
                for hover_h in [50, 100, 150, 200]:  # 离地高度
                    z = terrain_h + hover_h
                    
                    # 检查是否满足高度限制
                    if hover_h <= relay_params['max_hover_height']:
                        pos = (x, y, z)
                        
                        # 计算该位置的覆盖范围
                        coverage = compute_coverage_area(dem, pos, relay_params)
                        
                        # 计算悬停能耗
                        hover_power = relay_params['hover_power_kw']
                        
                        candidates.append({
                            'position': pos,
                            'coverage': coverage,
                            'hover_power': hover_power
                        })
    
    return candidates
```

### Algorithm 4: 中继部署优化（Set Cover Problem）

**输入**：
- 候选中继位置
- 需要覆盖的运输任务
- 中继机数量限制

**输出**：
- 选中的中继位置集合
- 每个中继的服务时段

**方法**：基于文献[2]的MILP建模 + 贪心启发式

```python
def optimize_relay_deployment(candidates, transport_missions, relay_limit):
    """
    最小化中继机数量，同时覆盖所有通信需求
    
    方法：贪心Set Cover
    """
    selected_relays = []
    uncovered_missions = set(transport_missions)
    
    while uncovered_missions:
        # 选择覆盖最多任务的候选位置
        best_candidate = None
        max_coverage = 0
        
        for candidate in candidates:
            # 计算该候选位置能覆盖的未覆盖任务数
            covered = compute_covered_missions(candidate, uncovered_missions)
            
            if len(covered) > max_coverage:
                max_coverage = len(covered)
                best_candidate = candidate
        
        if best_candidate is None:
            break  # 无法继续覆盖
        
        # 选中该候选位置
        selected_relays.append(best_candidate)
        
        # 更新未覆盖任务
        covered = compute_covered_missions(best_candidate, uncovered_missions)
        uncovered_missions -= covered
        
        if len(selected_relays) >= relay_limit:
            break
    
    return selected_relays
```

### Algorithm 5: 时间窗协调

**输入**：
- 运输机飞行计划（问题二结果）
- 中继机部署方案
- 通信需求时段

**输出**：
- 协调后的中继服务时段
- 能源分配方案

**方法**：基于文献[3][8]的协同控制

```python
def coordinate_time_windows(transport_schedule, relay_deployment, comm_requirements):
    """
    协调运输机与中继机的时间窗
    
    确保：运输机需要通信时，中继机已在位
    """
    relay_service_times = {}
    
    for relay in relay_deployment:
        # 找到需要该中继服务的所有运输任务
        served_missions = relay['covered_missions']
        
        # 计算服务时段：最早开始 ~ 最晚结束
        earliest_start = min(mission['start_time'] for mission in served_missions)
        latest_end = max(mission['end_time'] for mission in served_missions)
        
        # 中继需要提前到达（部署时间）
        deploy_time = 10  # 提前10分钟
        relay_service_times[relay['id']] = {
            'deploy_start': earliest_start - deploy_time,
            'service_start': earliest_start,
            'service_end': latest_end,
            'return_time': latest_end + 5
        }
    
    return relay_service_times
```

**输出**：

```python
def multi_objective_optimization(transport_plan, relay_plan, weights):
    """
    多目标优化：及时性、完成时间、能耗、架次数
    
    使用NSGA-II生成Pareto前沿
    """
    # 定义目标函数
    objectives = {
        'timeliness': lambda x: compute_delivery_delay(x),
        'completion_time': lambda x: compute_makespan(x),
        'energy': lambda x: compute_total_energy(x),
        'num_trips': lambda x: compute_num_trips(x)
    }
    
    # 初始化种群
    population = initialize_population(transport_plan, relay_plan, pop_size=100)
    
    # NSGA-II迭代
    for generation in range(100):
        # 计算目标值
        for individual in population:
            individual.objectives = {
                obj_name: obj_func(individual) 
                for obj_name, obj_func in objectives.items()
            }
        
        # 非支配排序
        fronts = non_dominated_sorting(population)
        
        # 拥挤度计算
        for front in fronts:
            crowding_distance(front)
        
        # 选择、交叉、变异
        offspring = genetic_operators(population)
        population = select_next_generation(population + offspring)
    
    # 返回Pareto前沿（第一前沿）
    pareto_front = fronts[0]
    
    # 根据权重推荐一个解
    recommended = weighted_selection(pareto_front, weights)
    
    return pareto_front, recommended
```

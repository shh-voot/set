# 问题二：异构无人机与共享电池调度

## 1. 输入

读取官方80箱清单、15个服务区、DEM、A/B/C机型参数、实体无人机数量和共享电池数量，并读取问题一采用的官方单架次可行性计算逻辑。

## 2. 任务生成

按服务区和官方截止时间分组，对每个机型执行载荷、体积和DEM能耗可行性组批。每个候选方案记录架次数、总能耗和任务时长。

## 3. 机型选择

使用截止期优先（EDD）和机队稀缺性反馈：计算候选机型在当前已分配任务下的完成波次、任务时长和能耗，选择综合得分最小的方案。首批保障货箱的官方截止时间优先级高于普通货箱。

## 4. 离散事件调度

按截止时间、货箱数量和优先系数排序。每个任务选择最早可用的同型实体无人机和共享电池，任务开始时间取两者可用时间最大值。

任务结束后：

- 更新无人机可用时间；
- 按官方两阶段充电模型计算电池充电时间；
- 更新共享电池可用时间；
- 校验无人机和电池编号未超过官方库存。

## 5. 全局校验

- 80箱唯一覆盖；
- 逐箱交付时间不超过官方截止时间；
- A/B/C实体无人机不超过4/2/2；
- A/B/C共享电池不超过6/4/4；
- 每架次能量不超过安全可用电量。

## 6. 当前结果

- 49架次；
- 系统完成时间205.6148 min；
- 80箱全部按时；
- 总运输能耗106.2827 kWh；
- A/B/C架次23/14/12；
- 官方机队和共享电池均未超库存。

                 华为杯D题 - 可视化方案总体规划

## 📊 可视化设计原则

1. **多样性**: 每个问题使用3-5种不同类型的图表
2. **创新性**: 使用高级可视化（3D、山脊图、小提琴图等）
3. **学术性**: 600 DPI高分辨率，统一配色方案
4. **信息量**: 每张图传达清晰的洞察

================================================================================
## 问题一：单架次配送方案优化
================================================================================

### ✅ 已完成的可视化 (6张)

1. **服务区分布图** (2D散点图 + 连线)
   - 地理空间分布
   - 机型选择可视化

2. **无人机性能对比** (2×2柱状图)
   - 使用频次
   - 平均载重
   - 平均能耗
   - 平均飞行时间

3. **资源利用率分析** (多子图)
   - 重量利用率
   - 体积利用率
   - 能耗利用率

### 🎯 建议新增可视化 (5-7张)

#### 1. **三维点云图 (3D Scatter Plot)**
```python
# 展示服务区的三维空间分布
X轴: 经度
Y轴: 纬度
Z轴: 海拔高度
点大小: 货物数量
点颜色: 选用机型
```
**洞察**: 地形对机型选择的影响

#### 2. **山脊图 (Ridgeline Plot)**
```python
# 展示不同机型的能耗分布
每条山脊: 一种机型
横轴: 能耗 (kWh)
纵轴: 概率密度
```
**洞察**: 三种机型的能耗分布差异

#### 3. **小提琴图 (Violin Plot)**
```python
# 展示载重、体积、能耗的分布特征
X轴: 指标类型 (重量/体积/能耗)
Y轴: 利用率 (%)
小提琴宽度: 数据分布密度
```
**洞察**: 约束瓶颈的统计特征

#### 4. **热力图 (Heatmap)**
```python
# 服务区 × 机型 适配矩阵
行: 15个服务区
列: A/B/C三种机型
颜色: 适配度得分
```
**洞察**: 为什么B型最优

#### 5. **雷达图 (Radar Chart)**
```python
# 三种机型的多维能力对比
维度: 载重、续航、能效、速度、体积
三条多边形: A/B/C型
```
**洞察**: 综合性能对比

#### 6. **桑基图 (Sankey Diagram)**
```python
# 能耗流向分解
左侧: 各服务区
中间: 能耗阶段 (起飞/巡航/下降/悬停)
右侧: 总能耗
```
**洞察**: 能耗分布的流向

#### 7. **等高线图 (Contour Plot)**
```python
# 地理空间的能耗热力分布
X轴: 经度
Y轴: 纬度
等高线: 能耗水平
```
**洞察**: 空间分布的能耗模式

## 问题二：多架次调度优化
================================================================================

### ✅ 已完成的可视化 (4张)

1. **甘特图 (Gantt Chart)** - 时间轴调度
2. **利用率分析** (2×2柱状图)
3. **时间对比** - 问题一vs问题二
4. **充电分析** - 充电频次和充电率

### 🎯 建议新增可视化 (6-8张)

#### 1. **3D甘特图 (3D Gantt)**
```python
# 三维时空调度
X轴: 时间
Y轴: 无人机ID
Z轴: 能量状态 (电量%)
颜色: 任务类型
```
**洞察**: 能量-时间-资源三维关系

#### 2. **流线图 (Streamgraph)**
```python
# 能耗随时间的流动
X轴: 时间 (0-300分钟)
Y轴: 各无人机的瞬时功率
颜色: 不同无人机
```
**洞察**: 能耗的时间演化

#### 3. **和弦图 (Chord Diagram)**
```python
# 服务区之间的路径关系
节点: 调度中心 + 15个服务区
弧线: 飞行路径
弧线粗细: 飞行频次
```
**洞察**: 网络拓扑结构

#### 4. **并行坐标图 (Parallel Coordinates)**
```python
# 多维任务特征对比
坐标轴: 开始时间/持续时间/载重/能耗/距离
每条线: 一个任务
颜色: 执行的无人机
```
**洞察**: 任务的多维度特征模式

#### 5. **树状图 (Treemap)**
```python
# 时间分配的层级结构
第一层: 各无人机
第二层: 飞行/充电/准备
矩形大小: 时间占比
```
**洞察**: 时间分配的层级关系

#### 6. **瀑布图 (Waterfall Chart)**
```python
# 从问题一到问题二的时间节省分解
起点: 问题一总时间
下降: 并行节省
上升: 充电时间
终点: 问题二完成时间
```
**洞察**: 时间改进的构成

#### 7. **蜂窝图 (Hexbin Plot)**
```python
# 任务在时空中的密度分布
X轴: 时间
Y轴: 空间距离
蜂窝颜色: 任务密度
```
**洞察**: 时空分布的热点

#### 8. **日历热力图 (Calendar Heatmap)**
```python
# 如果扩展到多天调度
每个格子: 一天
颜色: 当天完成的任务数/能耗
```
**洞察**: 长期调度的模式

## 问题三：中继站部署优化 (待实现)
================================================================================

### 🎯 推荐可视化方案 (7-9张)

#### 1. **3D地形图 + 中继站位置**
```python
# 三维地理可视化
X, Y: 经纬度
Z: 海拔高度
表面: 地形起伏
点: 中继站候选位置
```
**洞察**: 地形对中继站的约束

#### 2. **通信覆盖热力图**
```python
# 2D热力图叠加
底图: 地理区域
热力: 信号强度
圆圈: 中继站覆盖范围
```
**洞察**: 覆盖的盲区和重叠

#### 3. **Voronoi图**
```python
# 泰森多边形
每个多边形: 一个中继站的服务范围
颜色: 负载均衡程度
```
**洞察**: 空间划分的合理性

#### 4. **网络拓扑图**
```python
# 图论可视化
节点: 调度中心/中继站/服务区
边: 通信链路
边粗细: 通信量
```
**洞察**: 网络的连通性和瓶颈

#### 5. **能见度矩阵图**
```python
# 视距分析
行列: 所有位置点
颜色: 是否可见 (有/无障碍)
```
**洞察**: 视距约束的模式

#### 6. **3D射线追踪图**
```python
# 通信路径的三维可视化
起点: 服务区
终点: 调度中心
路径: 经过中继站的射线
```
**洞察**: 通信路径的几何关系

#### 7. **力导向图 (Force-Directed Graph)**
```python
# 优化过程的可视化
节点: 中继站候选位置
边: 连接关系
力: 覆盖力 vs 距离力
```
**洞察**: 优化算法的动态过程

#### 8. **等值线图 (Isoline Map)**
```python
# 通信质量的空间分布
等值线: 信号强度
渐变色: 信噪比
```
**洞察**: 通信质量的空间变化

#### 9. **决策树可视化**
```python
# 中继站选址决策
树节点: 评价指标
分支: 判断条件
叶节点: 选址结果
```
**洞察**: 决策逻辑的透明化

## 📐 技术实现计划
================================================================================

### Python库选择

1. **基础**: matplotlib, seaborn
2. **3D**: mpl_toolkits.mplot3d, plotly
3. **地理**: geopandas, folium, contextily
4. **网络**: networkx, graphviz
5. **高级**: plotly, altair, bokeh
6. **交互**: ipywidgets, dash

### 配色方案

统一使用 paper-color skill 的学术配色：
- **分类**: fresh-sky 调色板
- **连续**: terracotta-focus 调色板
- **发散**: 蓝-橙双色系

### 输出规范

- **分辨率**: 600 DPI (论文级)
- **格式**: PNG (主) + PDF (矢量备选)
- **尺寸**:
  - 单图: 10×8 inches
  - 组合: 14×10 inches
  - 特殊: 根据内容调整

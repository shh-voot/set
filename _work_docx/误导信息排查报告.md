### 2.2 附录2 定义了什么、**"通用航段能耗模型"没给**
已定义的（附录2）：
- 等效航程 `L_g(q)=L_g^0-(L_g^0-L_g^F)(q/Q_g)^{3/2}`，`0≤q≤Q_g`
- 航段飞行时间 `t_gij = h+_ij/v_g↑ + d_ij/v_g^c + h-_ij/v_g↓`
- 航段能耗 `E_gij(q) = E_gij^hor(q) + E_gij^up(q)`；**下降能耗效率=0 → 不单独计算下降附加能耗**
- 返航约束 `E_p^T = Σ E_gij(q_pij) ≤ (1-ρ_g)E_g^use`（ρ_g 取表里的返航电量下限 20%）
- 充电 `t_chg(s) = T_full[0.65(0.9-s)/0.9+0.35] (s<0.9)`；`T_full·0.35(1-s)/0.1 (0.9≤s≤1)`

**没给的**：`E^hor(q)` 和 `E^up(q)` 的解析式。附录2 只有 \(\Sigma\) 这一条约束式，**没有给出功率/能耗的显式关系**（比如 `P_hor` 与载荷的关系、爬升功率是否含重力势能项 `mgh/η`、`η` 是否用表里 0.72）。

## 5. 建议在论文里显式"钉死"的口径（用来反将一军）

因为上面 2.1–2.3 存在歧义，**以下 8 条建议在"模型假设"里逐条写明并给出公式**，既避免被扣分，也能与其他队伍拉开差异：

1. **节点作业高度**：O01 = 表内海拔 **127.7 m**；服务区 = 表内海拔 **+30 m**（附录2 原话），**一律取表内海拔，不采样 DEM**
2. **巡航海拔**：航段所经 DEM 像元最高地面高程 **+50 m**；DEM 采样一律用**像元中心规则**（`floor(deg×3600)/3600 + 1/7200`）并断言 lat/lon 未反转
3. **航段时间的 5 个附加时间**：给出 `T_架次 = 工位固定准备 + Σ(爬升+巡航+下降) + Σ(基础交接 + 箱数×每箱交接)` 的显式公式（或明确声明"交接时间不计入任务完成时间，只计入地面周转"）
4. **"最大安全载荷"判据**：明确 = `max q` s.t. `E_gij(q)` 往返总能耗 `≤ (1−20%)·E_g^use`（并说明用等效航程法）
5. **返航安全余量**：`ρ_g` 直接取表内"返航电量下限"20%，并做灵敏度分析（问题一第(4)问要求）
6. **期望送达时间**：明确"医疗物资 + 首批货箱为**硬约束**，其余为**软目标（加权惩罚）**"，并单列 S012/S014 的 3600/7200 特殊点

## 🎯 问题描述

在山区洪涝灾害中，15个受灾服务区需要接收80个货箱的应急物资。由于地形复杂、道路中断，需要使用无人机进行配送。主要约束包括：

- **地形约束**: 基于30m分辨率DEM数据的3D地形
- **载荷约束**: 3种无人机机型（A/B/C），官方库存A4架/B2架/C2架
- **能耗约束**: 考虑爬升、巡航、载重的精确能耗模型
- **通信约束**: 基于视距(LoS)的通信链路，2架中继无人机（R01/R02）
- **资源约束**: 共享电池A6组/B4组/C4组，中继能源组件6组

## 🔬 核心算法

### 问题一
- **FFD装箱算法**（First-Fit Decreasing）
- **机型选择优化**（基于载重-能耗比）
- **DEM地形能耗计算**（爬升/巡航/下降三阶段）

### 问题二
- **贪心调度算法**（最早截止时间优先）
- **离散事件仿真**（电池充放电动态管理）
- **资源峰值控制**（实体无人机和电池约束）

### 问题三
- **DEM视距通信判定**（Line-of-Sight）
- **Set Cover中继部署**（集合覆盖优化）
- **双向链路预算**（发射功率、接收灵敏度、系统损耗）

### 问题四
- **并查集分组**（中继覆盖关系）
- **负载均衡**（人口均衡贪心）
- **峰值资源统计**（时间轴重叠分析）

## ⚠️ 重要说明

### 问题一方案选择

项目曾有一个"18架次方案"，经验证**该方案严重违规**：
- 9个架次超过30kg载重限制（最大78kg，超标160%）
- 实际上是问题二的多点访问解法

**最终采用37架次严格约束方案**，该方案：
- ✅ 完全符合赛题约束
- ✅ 覆盖全部80箱
- ✅ 无任何违规

详细对比见 [CLEANUP_REPORT.md](CLEANUP_REPORT.md)

### 问题四资源缺口

问题四出现的资源缺口（2批次缺C2架，3批次缺A1/B2/C3架）是**合理的**：
- 题目要求"资源不得跨组调配"
- 各组需要独立的资源池
- 分组导致峰值叠加
- 这正是题目要研究的"任务分区对资源配置的影响"

详细分析见 [docs/q4_analysis.md](docs/q4_analysis.md)

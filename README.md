# 华为杯数学建模竞赛 - D题：山区洪涝灾害下无人机运输与通信协同优化

## 📌 项目概述

本项目针对山区洪涝灾害救援场景，建立了无人机应急物资运输与通信中继协同优化的完整数学模型和求解方案。

**竞赛信息**：
- 竞赛：华为杯数学建模竞赛
- 题目：D题 - 山区洪涝灾害下无人机运输与通信协同优化
- 时间：2026年

## 🎯 问题描述

在山区洪涝灾害中，15个受灾服务区需要接收80个货箱的应急物资。由于地形复杂、道路中断，需要使用无人机进行配送。主要约束包括：

1. **地形约束**：基于30m分辨率DEM数据的3D地形
2. **载荷约束**：3种无人机机型，不同载重和续航能力
3. **能耗约束**：考虑爬升、巡航、载重的精确能耗模型
4. **通信约束**：基于视距(LoS)的通信链路约束
5. **时间约束**：72小时内完成配送

## 🔬 核心创新

### 1. 真实地形集成
- 基于30m DEM数据的3D地形建模
- 视距(Line-of-Sight)通信链路判定
- 地形感知的能耗计算

### 2. 多目标优化框架
- 时间最小化
- 能耗最小化
- 覆盖率最大化
- 资源消耗最小化

### 3. 分层优化策略
- 货物装箱优化
- 路径规划
- 通信中继部署
- 批次调度

### 4. 离散事件仿真
- 电池充放电动态建模
- 资源瓶颈识别
- 缺货检测

## 📊 问题求解方案

### 问题一：单架次配送方案（100%完成）

**目标**：为每个服务区选择合适的无人机机型，确保能耗可行且效率最优。

**算法**：
- 贪心装箱算法（First-Fit Decreasing）
- 机型选择优化（基于载重-能耗比）
- 3D地形能耗计算

**当前结果**：18架次，80箱唯一覆盖，全部通过官方能量和等效航程校验。结果文件：`结果/问题一_18架次方案_修复版.xlsx`。

### 问题二：多架次运输调度（100%完成）

**目标**：在72小时内完成所有配送，最小化总完成时间。

**算法**：
- 贪心TSP路径规划（最近邻 + 2-opt优化）
- 并行多架次调度
- 电池管理（两阶段充电模型）

**当前结果**：49架次，完成时间205.6148分钟，80箱全部按时。结果文件：`结果/问题二_优化修复版.xlsx`。

### 问题三：通信中继协同（100%约束可行）

**目标**：在通信链路约束下优化运输与中继部署。

**算法**：
- 基于DEM的LoS通信判定
- Set Cover中继部署优化
- 运输-中继联合迭代

**当前结果**：使用官方R01/R02两架中继覆盖15/15服务区，49/49架次通信可用，80箱无迟到。结果文件：`结果/问题三_汇总_修复版.json`、`结果/问题三_运输调度_修复版.xlsx`。

### 问题四：批次划分与资源配置（资源缺口分析）

**目标**：将服务区划分为可并行执行的批次，分析资源需求。

**算法**：
- 基于通信冲突图的图着色算法
- 离散事件仿真（电池池管理）
- 资源瓶颈分析

**当前结果**：问题四读取问题二优化方案和问题三中继方案，分别计算2批次、3批次的峰值无人机、电池、充电桩和中继资源需求，并与官方库存比较。结果文件：`结果/问题四_2批次_修复版.xlsx`、`结果/问题四_3批次_修复版.xlsx`。当前结论是存在官方库存缺口，不能直接宣称2批次或3批次在现有库存下可执行。
